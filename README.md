# 마석고 1-3 학급 사이트

## 폴더 구조
```
index.html            뼈대 (로그인 화면은 HTML에 직접 들어 있어 즉시 표시)
assets/logo.svg       학교 로고 (브라우저가 캐시함)
css/style.css         스타일 전체 (번호 붙은 11개 구역으로 정리)
js/main.js            시작점: 로그인, 실시간 구독, 화면 그리기, 버튼 연결
js/firebase.js        Firebase·Cloudinary 설정과 데이터 위치
js/store.js           앱 상태, 권한 확인, 렌더 예약
js/utils.js           이스케이프, 날짜, 이미지 압축, 입력 보존 렌더링
js/dialog.js          <dialog> 모달 도우미
js/views/*.js         탭별 화면과 동작
```

## 새 버튼을 추가하는 방법
HTML에 `data-action="함수이름"`을 달고, 그 화면 파일 맨 아래 `actions`에 함수를 넣으면 됩니다.
값은 `data-id="${esc(값)}"`처럼 data 속성으로만 넘기고, 함수에서는 `el.dataset.id`로 읽습니다.
onclick="..." 안에 사용자 데이터를 넣지 마세요.

- 클릭: `data-action`
- 값 변경(체크박스, 선택 상자): `data-change`
- 폼 제출(Enter 포함): `<form data-submit="함수이름">`
- 입력 중 실시간 업데이트가 와도 지켜야 하는 칸: `data-keep` (+ `id` 또는 `data-key`)

## UI 개편 (2026-11) 변경 사항

- **탭 4개**: 오늘 · 시간표 · 일정 · 우리 반. 예전 주소(`#cal`, `#match`, `#cleaning`, `#duty`, `#suggest`, `#bannerManage`, `#admin`)는 새 탭으로 자동 연결돼요. 급식은 오늘 탭의 점심 칸(`#meal`)에서 들어갑니다.
- **오늘 탭**: 공지 한 줄 → 지금 수업(남은 시간) → 하루 타임라인(교시·점심 급식·종례 청소) → 일정/할 일/1인1역 카드. "지금" 표시는 시간표의 교시 시간(예: `08:40~09:30`)이 입력돼 있어야 작동해요.
- **일정 탭**: 캘린더와 대항전을 합쳤어요. [전체 | 수행평가 | 대항전] 필터, 날짜를 누르면 그날 일정이 아래에 나와요.
- **우리 반 탭**: 청소·당번 / 1인1역 / 건의 / (반장 이상) 배너 / (선생님·개발자) 관리.
- **편집 모드**: 시간표와 청소 설정 폼은 선생님 계정이 `편집`을 눌러야 보여요. 학생 화면이 깔끔해요.
- **상단 [나] 버튼 → 내 정보 시트**: 배너 켜기/끄기, 테마, 효과, 나만의 배경·글꼴, 비밀번호, 로그아웃이 모두 여기에 있어요.

### 나만의 배경·글꼴 (js/theme.js)
6색 팔레트(바다 먹색 `#0d2433`, 청록 `#0e8c96`, 민트 `#2ecf9a`, 칠판 흰색 `#f2f6f4`, 로고 주황 `#e9450b`, 로고 남색 `#1e2b5c`)로
배경(그라데이션 시작/끝 색 또는 단색)과 배경 위 글자색을 고르고, 글꼴은 기본(Pretendard) / 둥근(Gmarket Sans) / 시스템 중에서 골라요.
- 이 기기에 저장돼요(`classSite_ui`, `classSite_look`). 로그인 전 화면에도 적용돼요.
- 글자색이 배경과 너무 비슷하면(명암비 3 미만) 읽기 편한 색으로 자동 대체하고 안내해요.
- 팔레트 색을 바꾸려면 `theme.js`의 `PALETTE`와 `style.css` 맨 위 `--c-*` 변수를 함께 고치세요.
- 글꼴은 jsDelivr CDN에서 불러와요(Pretendard, Gmarket Sans). 막히면 시스템 글꼴로 보입니다.
